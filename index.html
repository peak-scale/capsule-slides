A cluster-scoped list is all or nothing.

Kubernetes RBAC can allow list namespaces, but it can't limit the result to just one tenant.

ClusterRole list namespaces
solar-* lunar-* nova-* ···

One permission returns every namespace in the cluster.

Capsule Proxy narrows this request in three steps.

Resolve the token to a user.

Capsule Proxy sends the bearer token to Kubernetes, which validates it and returns the caller's user and groups.

kubectl request Bearer ••••••
Capsule Proxy
TokenReview user + groups
Kubernetes API
A
Authenticated as alice@corp.example group: solar-owners

Map the user to namespaces.

Capsule combines namespaces from owned Tenants and any explicit grants.

solar-owners Tenant solar
Visible namespaces solar-production solar-staging solar-development

+ explicit RoleBinding or ProxySettings grants

Narrow the request.

The proxy turns the allowed names into a Kubernetes label selector and forwards the narrowed request.

GET /api/v1/namespaces
Filter namespaces
GET /api/v1/namespaces
?labelSelector=kubernetes.io/metadata.name in
(solar-production, solar-staging, …)
